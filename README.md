# sanctuaryos
This is **my** take on a SanctuaryOS Linux-based operating system. This is not official by any means, it merely is a fan-project for the DUSQK© universe. <3
This documentation is out of universe.

# The Directory
SanctuaryOS has a special user directory called ``.sanctos`` where your personal information is stored. Think of it as the Gaia Corp. cloud servers, but in your computer (we don't have that yet).
